<h1 align="center">Arthex modules</h1>

<p align="center">Add what you need to <a href="https://github.com/arthreto/Arthex">Arthex</a>, and nothing else.</p>

## Modules

| Module             | What it does                                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| **Color**          | Take a color from the screen with an eyedropper, pick one on a wheel and convert it to HEX, RGB, HSL and more. Windows only. |
| **Unit converter** | Lengths, weights, temperatures, data and more. Type `5 MB` or `30 cm in in` in the search bar, or open the tool.             |
| **Discord RPC**    | Create presence templates and switch between them: type of activity, texts, images, time, group and buttons. Windows only.   |

## Install a module

1. In Arthex, open **Settings → Modules → Catalog**, or **Add modules** at the end of All pages.
2. Click **Install**.

You can also download a `.arthex` file from the [Releases](https://github.com/arthreto/arthex-modules/releases) page and open it.

**Check for updates** in the Catalog shows when a module has a new version. Each part of a module can be turned off in **Settings → Modules**.

## Discord RPC

- It needs the Discord desktop app to be open.
- Create an application on the [Discord Developer Portal](https://discord.com/developers/applications) and paste its ID into your template.
- For images, use the name of an image imported on that application, or the address of a public image.
